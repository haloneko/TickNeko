# 控制台顶栏与账号菜单

`frontend/src/features/layout/Topbar.tsx` 管理主题切换、导航开关和账号菜单。

## 账号菜单

点击右上角头像打开或关闭菜单。外框以头像下方右侧为原点轻微展开并回稳，文字单独滑入，不随外框缩放；收起有 150ms 退场。
菜单保留同一个 DOM，快速切换可以反向过渡，不依赖卸载计时器。关闭立即设置 `inert`、`aria-hidden`，避免退场期间点到设置链接或退出按钮。
页面级指针监听负责点外部关闭，不使用会遮住头像按钮或被顶栏定位环境限制的全屏遮罩。

打开后焦点进入第一项；方向键、Home / End 移动焦点，Esc 关闭并回到头像；Tab 离开菜单和页面切换也会关闭。
系统选择减少动态效果时直接显示、隐藏，箭头也停止旋转过渡。

## 手工回归

1. 点击头像开关菜单，确认外框与文字分别进出，文字没有缩放变形。
2. 快速反复点击头像，确认最终开关状态一致；点页面空白和按 Esc 均能关闭。
3. 用键盘打开，检查第一项焦点、方向键循环、Home / End、Tab 离开及 Esc 后焦点回到头像。
4. 收起后确认菜单立即 `inert`，退场期间不能触发链接或退出按钮；重开后项目恢复交互。
5. 点击「个人设置」和「登录设备」，确认只导航一次且菜单关闭；不要通过真实退出操作验证动画。
6. 在窄屏和减少动态效果设置下检查位置、显隐以及键盘操作。
